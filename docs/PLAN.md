# GH-300 学習アプリ 実装計画（草案）

## ゴール
GitHub Copilot 認定試験 GH-300 の学習用 PWA。iPhone の Safari →「ホーム画面に追加」で使う。オフライン動作・個人利用前提。

## 方針
- スタック: **Vite + TypeScript + Preact**（またはバニラ TS）。サーバ不要の静的サイト。依存は最小限。
- データ: 問題は `data/questions.json`（静的）。学習履歴・ブックマーク・中断中の試験は **localStorage / IndexedDB** に保存（端末内のみ）。
- PWA: manifest + Service Worker（アプリシェルと問題 JSON をキャッシュ）、`apple-touch-icon`、safe-area 対応。
- ホスティング: GitHub Pages（HTTPS が必要なため）。
- UI: スマホ縦 1 カラム、タップ領域 44px 以上、ダークモード対応、`prefers-reduced-motion` 対応。

## 画面（モックアップ `mockup/index.html` で確認可能）
1. ホーム: 進捗サマリ、模擬試験ボタン、セクション一覧（正答率・進捗バー）
2. 学習設定: 学習モード（順番/未学習/最近不正解/直近3回不正解/ブックマーク）、言語、チャンク
3. 問題: 選択 → 回答 → 正誤と解説 → 次へ。ブックマーク
4. 模擬試験設定: 出題数、制限時間、ドメイン比率（公式配分/均等）
5. 模擬試験: タイマー、前へ/次へ、フラグ、一時中断
6. 中断中の試験: 進捗・経過・残り、再開 / 新規

## マイルストーン
- M0 モックアップ確認（今ここ）
- M1 プロジェクト雛形 + PWA + ホーム/学習/問題（ローカル保存）
- M2 模擬試験（タイマー・中断再開・採点・結果画面）
- M3 統計・ブックマーク・復習モード
- M4 問題データ拡充、Pages 公開、実機（iPhone）確認

## 要確認事項
- **問題データの出所**: 公式の試験問題の複製は不可。自作問題（公式ドキュメント準拠）を作る前提でよいか。数・作成方法（Claude に生成させレビュー）。
- ドメイン配分（D1 18% / D2 28% / D3 13% / D4 13% / D5 14% / D6 14%）と試験条件（60 問/100 分/700 点）は参考画像の値。最新の公式スキル一覧で要確認。
- 画面の「フルアクセス解放（課金）」は不要と想定（個人利用）。
- 英語/バイリンガル表示を実装するか（問題の英語版が必要になる）。
- 技術スタック（Preact か バニラか）。
